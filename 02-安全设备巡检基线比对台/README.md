# 安全设备巡检基线比对台

把安全设备（WAF / IPS / 防火墙 / 审计设备）的配置文本丢进去，规则引擎自动比对基线，输出「合规 / 不合规 / 不适用」，**每条判定都能展开看命中的原始配置行**。

单文件，双击 `安全设备巡检基线比对台.html` 即可使用，无需安装。

## 解决的问题

等保 / 基线巡检要逐台核对几十个检查点，靠肉眼比对有两个老问题：

- **漏项**：项太多，翻着翻着就跳过了
- **不可举证**：说"不合规"，客户问"哪条配置不合规"，答不上来

这个工具把每一步都留痕：判定结果 → 命中规则 → 命中的原始配置行号。

## 功能

- **22 条内置基线项**：默认账号、口令复杂度、登录失败锁定、Telnet 明文、HTTPS 管理、日志外发、NTP 同步、访问控制策略等
- **多设备横向对比**：一份配置一列，同一检查项跨设备一眼看出谁不合规
- **人工核查层**：内置规则判不了的（如"是否部署了双因素"）转人工勾选，保留证据与问题描述
- **清单 JSON 导入**：吃「安全巡检剧本运行器」的导出格式，按设备自动拆列
- **导出**：CSV 矩阵 / Markdown / HTML 报告 / JSON

## 判定引擎的几个关键行为

这些细节决定了结论可不可信：

| 行为 | 说明 |
|---|---|
| **注释行不计数** | `# 本设备未配置 NTP` 这种注释不会被当成"已配置" |
| **`undo` 命令排除** | 配置里有 `undo telnet server` 时，不判定为启用了 Telnet |
| **原始判定保留** | 人工改判后仍保留自动判定结果，并用 `*` 标记 |
| **不适用**：显式标注 | 该设备没有这个功能时标"不适用"，不混淆为"合规" |
| **等保映射到二级子类** | 只映射到 8.1.2 / 8.1.3 / 8.1.4 / 8.1.5 这类子类，不编造细项编号 |

## 用法

1. 导入配置（一个文件 = 一台设备，文件名自动做设备名；也支持一个文件含多台设备）
2. 选择要跑的内置规则
3. 点「开始比对」看矩阵
4. 判不了的项在「人工核查层」补充
5. 导出报告

设备配置会**自动保存在浏览器本地**，刷新或关掉页面不会丢。

## 配置从哪来

| 设备 | 方法 |
|---|---|
| 华为 / H3C | `display current-configuration` |
| Cisco | `show running-config` |
| 深信服 / 天融信 / 绿盟 | 控制台「配置备份」导出 |
| 网上下载的样例 | 厂商文档里的配置举例、实验环境导出的配置，都可直接用 |

详细操作见 [使用说明](使用说明.md)。
