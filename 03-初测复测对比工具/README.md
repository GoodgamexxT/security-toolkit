# 初测 vs 复测对比工具

比对两次扫描结果，自动分出**已修复 / 仍存在 / 新增 / 疑似**。

单文件，双击 `初测复测对比工具.html` 即可使用，无需安装、无需联网。

## 为什么不用 Excel

手工核对最常犯两个错：

| 错误 | 后果 |
|---|---|
| 按"漏洞名"粗略匹配 | 同一漏洞在多个端口/路径各有一条，修了 2 个还剩 1 个，会被误判成"已修复" |
| 严格匹配不到就直接算修复 | 管理员只是改了端口或路径，结论就变成"已修复"，实际漏洞还在 |

这个工具的做法是：**严格匹配 + 疑似缓冲**。严格匹配不上、但宽松匹配能配上的，单独归入「疑似（需人工）」，不直接算修复。

## 功能

- 匹配粒度可切换：`资产+漏洞名+端口+路径`（严格）/ `资产+漏洞名`（宽松）
- 同一漏洞的多端口多路径**分别核对**
- 等级变化会标出（如 中危 → 高危 ↑升级）
- 按资产聚合：一眼看出哪台机器没清干净
- 导出 CSV（带 UTF-8 BOM，Excel 直接开）/ HTML 核对报告

## 支持的输入

| 来源 | 说明 |
|---|---|
| 本工具模板 HTML | 内嵌 `const findings = [...]` 数组，精确解析 |
| 通用厂商 HTML 表格 | 按表头关键词自动识别列（资产/漏洞/等级/端口/路径） |
| CSV / TSV | 直接粘贴或选文件 |

解析器按引号状态做括号配对，能正确处理证据字段里的 `${jndi:ldap://}` 这类内容——用简单正则切对象会把它整条丢掉。

## 用法

1. 左边放基线（初次扫描），右边放复测
2. 选匹配粒度，点「开始对比」
3. 看四列结果，点任意条目可查看证据原文
4. 导出 CSV 或核对报告

## 验证

用一对真实报告（初测 68 条 / 复测 65 条）验证过：已修复 10、仍存在 58、新增 7，且 `10 + 58 = 68`、`58 + 7 = 65` 算术自洽。
