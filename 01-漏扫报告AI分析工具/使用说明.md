# 漏扫报告 AI 分析工具 · 使用说明

> 单文件网页工具，双击 `漏扫报告AI分析工具.html` 即可用，**不需要联网安装任何东西**，也不需要 Python/Node。
> 设计目标：现场扫完的报告 → 脱敏 → 交给 AI 做研判和加固建议 → 还原成能交付的报告。

---

## 一、它解决什么问题

现场漏扫报告通常几千条、大量重复、误报一堆，人工翻一天也看不完。这个工具把整条链路固化成六步：

```
① 导入报告 → ② 脱敏 → ③ AI 分析 → ④ 还原出报告
                              ↘ ⑤ 修复验证 Diff（复测比对）
                              ↘ ⑥ 优先级重算（KEV/EPSS/CVSS/暴露面）
```

前四步是「把报告交给 AI」；后两步是**确定性的交叉验证**——不依赖 AI 的判断，用规则算出「到底修没修好」和「今天到底该先修哪个」。

关键点：**原始 IP、域名永远不出你的电脑**。发给 AI 的是 `[[IP_001]]` 这种占位符，AI 分析完你再把真实值换回去。后两个模块的结果同样可以一键脱敏后再发出去。

---

## 二、前四步怎么走

### 第 1 步 · 导入

- 点“点击选择文件”或把报告拖进去，支持 `.html / .htm / .csv / .txt / .log / .json`
- **厂商 HTML 报告**（绿盟/天融信/安恒等）会被自动解析：提取所有表格 + 正文
- 想先熟悉流程，点「载入示例报告」

解析完会显示：字符数、识别到几张表格、几个 IP、几个域名。确认没问题再往下。

两个开关：

| 开关 | 用途 |
| --- | --- |
| 只用表格内容 | 丢掉大段说明文字，只留漏洞明细表，最省 token |
| 压缩长描述 | 每行只留前 12 列、单元格截到 120 字，报告特别大时开 |

### 第 2 步 · 脱敏

勾选要脱敏的类别（IP / 域名 / 邮箱 / MAC），可选填「额外要脱敏的字符串」（公司名、系统名等，用逗号分隔），点「执行脱敏」。

会显示识别出的每一项，例如：

```
[[IP_001]] ← 10.20.30.11
[[DOM_001]] ← app.corp-example.com
```

**编号按在报告里首次出现的顺序**，这样报告读起来自然。

点「导出映射表」会存一个 `mapping-XXXX.json` —— **里面是真实 IP 和域名**。

> ⚠️ 这个文件只用于最后还原。**绝对不能**发给 AI，也别放在共享目录。用完可以删。

### 第 3 步 · AI 分析

**方式 A（推荐，最稳）：复制粘贴**

点「复制『提示词 + 脱敏数据』」，粘贴到任意 AI 对话里。提示词已经内置了完整要求（见下文第四节）。

**方式 B（快）：页面内直连**

填 Base URL / 模型 / API Key，点「开始分析」，结果流式显示在页面上。

- 默认 `https://api.deepseek.com/v1` + `deepseek-flash`
- 也支持任何 OpenAI 兼容接口（通义、Kimi、硅基流动等）
- Key 只存在本机浏览器 localStorage，不联网上传
- 已实测：从本地文件页面（`file://`）直连 DeepSeek 返回 200，浏览器不拦

**两种方式拿到结果后，都进第 4 步。**

### 第 4 步 · 还原并出报告

把 AI 的回复整段粘贴到文本框，工具自动把 `[[IP_001]]` 换回 `10.20.30.11`，并渲染成排版好的报告。

- 勾了「输入时自动还原」的话，粘贴后 0.9 秒自动处理
- 有占位符没匹配上会**红字提示**，不会静默漏掉
- 可下载 **HTML 报告**（带样式，可直接发给客户）、**Markdown**，或打印成 PDF

如果关掉页面重新打开，在第 4 步点「导入 mapping.json」就能继续还原。

## 三、脱敏的准确性（这是最容易翻车的地方）

工具做了这些防误伤：

| 场景 | 处理 |
| --- | --- |
| `index.php` / `sqli_str.php` / `backup.rar` | **不会**当成域名。域名最后一段必须是真实顶级域（内置白名单：com/cn/net/org/edu/gov/local/corp…） |
| `2.14.1` 版本号 | 不是 4 段数字，不会被当成 IP |
| `CVE-2021-44228` | 不含点号结构，不会被误脱敏 |
| `2026-10-22` 日期 | 不匹配 |
| `10.20.30.11:8080` | 只脱 IP，**端口保留**（端口对研判有用） |
| `10.0.0.0/24` | 只脱 IP，**掩码保留** |
| `http://app.corp-example.com:8080/api/login` | **只脱主机名**，路径 `/api/login` 保留（路径本身是漏洞线索） |
| `www.a.com` 与 `a.com` | 分别映射成两个占位符，长值优先替换，不会互相吃掉 |
| `fe80::1`、`::1`、`2001:db8:…` | IPv6 完整/压缩/回环形式都支持 |

还原时做了**宽松匹配**：AI 如果把 `[[IP_001]]` 写成 `[[ ip_1 ]]`、`IP-001`、`IP_001`，也能正确换回来。

## 四、提示词里写了什么（对应你说的两组工作）

工具会把下面这套要求连同脱敏报告一起发出去：

**任务一 · 报告初筛与研判**

- 去重归并：按漏洞类型 / CVE / 影响资产聚类，注明每条由多少条原始记录合并
- 误报初筛：给出「疑似误报 / 需确认 / 基本可信」+ 置信度（高中低）+ 判断依据
- 可利用性研判：有无公开 EXP、是否需认证、是否公网暴露、利用后果
- 优先级排序：Top 10 + 独立列「今日必修清单」，每条标 24h / 7d / 迭代

**任务二 · 加固闭环**

- 可落地修复：Ansible playbook / Bash 脚本 / Terraform 片段草稿，**强制标注「需 Dry-run + 人工审核」**，涉及 SSH、防火墙、认证策略要额外警示风险与回滚方式
- 基线核查：解析 CIS / 等保检查项，给批量检测脚本草稿 + 逐条解释「为什么不合规 / 怎么改 / 怎么验证」

**防幻觉约束**（这条很重要）

- 禁止编造 CVE、EXP 链接、厂商公告，不确定就标“需核实”
- 明确告知 AI：结论是概率性的，高危项必须人工复核
- 强制要求输出末尾附一个 JSON 代码块（`findings` / `today_list` / `hardening` / `manual_review`），方便以后做程序化汇总

## 五、第 5 步 · 修复验证 Diff（跨次扫描比对）

**解决的问题**：修复之后怎么证明真修掉了？靠人工逐条比两次报告，既慢又容易漏。

### 怎么用

1. 左边放**基线扫描**（上一轮），右边放**复测扫描**（本轮），各自可以点选文件或直接粘贴 CSV/TSV
2. 自动识别表头字段（资产/漏洞名/CVE/端口/URL/等级），**识别错了就在「字段映射」里手动改**——每个字段一个下拉框，选对应的列
3. 选匹配模式，点「开始比对」

### 匹配模式（关键设计点）

匹配键不是「IP + 漏洞名」，那样端口和路径就丢了。默认用的是组合键：

```
asset + vuln_id + port + path
```

| 模式 | 键 | 适用 |
| --- | --- | --- |
| **严格**（默认） | 资产+漏洞+端口+路径 | 报告规范、同端口同路径的场景，结果可直接采信 |
| 中等 | 资产+漏洞+端口 | 路径有轻微变化（参数顺序、大小写）时 |
| 宽松 | 仅资产+漏洞 | 报告格式差异大、想快速过一遍；**不保证准确**，只用来找线索 |

宽松/中等模式下，靠「放宽」才匹配上的条目**不会**被直接判成「仍存在」或「已修复」，而是单独进第四栏 **❓疑似（需人工）**，写明「端口/路径有变化，需人工确认是否同一漏洞」。这样规则不确定的地方不会被静默吞掉。

勾「忽略 URL 查询串」可以把 `?id=1` 这类参数差异排除掉，减少假新增。

### 结果怎么看

- 顶部四个数字：已修复 / 仍存在 / 新增 / 疑似，外加「上轮→本轮条数」
- 三栏卡片：每条显示资产、端口、漏洞名、CVE、路径，以及**上一轮等级 → 本轮等级**（`↑` 升级 / `↓` 降级 / `=` 不变）
- **筛选**：右上角下拉「只看新增高危」/「只看高危及以上」，评审会上直接看该看的
- **按资产聚合**：勾上后切换成表格，每台主机一行，显示总条数/已修复/仍存在/新增/疑似，并标 **已清零 / 未清零**，未清零的排前面
- 搜索框可按资产、漏洞名、CVE 过滤

### 输出

- **导出 CSV**（带 BOM，Excel 打开不乱码）
- **复制结果（自动脱敏）**：把比对结果转成文本，自动跑一遍脱敏再放剪贴板，可以直接贴给 AI 让做二次判断

## 六、第 6 步 · 可解释优先级重算（KEV + EPSS + CVSS + 暴露面）

**解决的问题**：漏扫器给的「高危/严重」是 CVSS 静态分，但「今天该先修哪个」还取决于是否在野利用、公网可达性。AI 的判断有概率性，这里给一个**确定性的、可复算的**底稿做交叉验证。

### 怎么用

1. 粘贴归一后的漏洞表（CSV/TSV），或每行只写一个 CVE 编号
2. 拉情报数据（三选一，可叠加）：
   - **联网补全 EPSS + KEV**：EPSS 走 FIRST 官方接口，KEV 走 jsDelivr 上的 CISA 官方镜像（官方站不给 CORS 头，浏览器拉不了）
   - **导入 KEV JSON**：现场没网时，提前下好 CISA 的 `known_exploited_vulnerabilities.json` 拖进来
   - **手工粘贴**：EPSS 每行 `CVE,值`；KEV 每行一个 CVE
3. 拖权重滑块，表格**实时重排**

### 打分公式（完全透明）

```
score = 100 × Σ(wᵢ × vᵢ) / Σwᵢ
  KEV     v = 0/1（在野利用）
  EPSS    v = 0~1（利用概率）
  CVSS    v = cvss/10（没有就用等级推定：严重9.5/高危8.0/中危5.5/低危2.5）
  暴露面  v = 0/1（域名和公网 IP 记 1，RFC1918 私网及回环记 0）
```

权重会自动归一化，四项加起来不必等于 100。默认按 VulnPilot 口径：**KEV 40 / EPSS 35 / CVSS 15 / 暴露 10**。另有一个可选开关「需认证项打 7 折」。

### 结果怎么看

每一行都带**可解释拆解**，例如：

```
KEV=是，贡献 40.0；EPSS=0.940，贡献 32.9；CVSS=9.5，贡献 14.3；公网暴露，贡献 10.0
```

不是黑盒数字——你能指着某一行说「它排第一，是因为在野利用 + 公网可达，不是因为 CVSS 高」。

数据没加载时会**明确告警**（「KEV 数据未加载 → 该组分按 0 计，排序会偏保守」），不会假装算得很准。

可以把第 5 步 Diff 结果里「新增 + 仍存在」的条目**一键带入**这里重排，形成「复测 → 排序 → 定修复顺序」的闭环。

## 七、已验证的项

开发时跑了真实浏览器测试，不是“看起来能用”：

- **脱敏核心 12 项单测**：实体识别、误报排除、长值优先替换、IPv6、还原一致性（脱敏再还原与原文逐字节相同）
- **Diff / 评分核心 48 项单测**：CSV 引号解析、字段自动映射、归一化、组合键区分端口/路径、三分类守恒、宽松模式疑似分离、资产聚合清零判定、评分公式自洽、情报解析
- **DOM 全流程 46 项**（Chrome headless 真实 DOM）：前四步 22 项 + 新增两模块 24 项，全程零未捕获异常
- **浏览器直连 API**：`file://` 页面请求 DeepSeek 返回 HTTP 200
- **在线情报源实测**：EPSS 接口返回真实数据（CVE-2021-44228 = 0.99999）；KEV 镜像 1.75 MB / 1756 条，catalog 版本 2026.10.23，CORS 为 `*`

## 八、已知限制

1. **HTML 报告靠通用表格提取**，字段位置不固定。如果某厂商报告把 IP 写在图片里、或表格结构特殊，可能提取不全。**给我一份真实样本，我可以加精确字段映射**（把“受影响资产”“漏洞名称”等列名硬绑定）。
2. **PDF / XLSX 暂不支持**，先在扫描器里导出 HTML 或 CSV。
3. 单次发给 AI 的内容上限约 12 万字符，超了会截断并提示。报告特别大时开「压缩长描述」，或分批次分析。
4. AI 的误报过滤是**概率性的**，高危结论必须人工复测，不能直接当结论交付。
5. 脱敏只覆盖 IP/域名/邮箱/MAC 和自定义词，**覆盖不到**：公司名称（要自己填进自定义词）、内网主机名（`WIN-ABC123` 这种）、人员姓名、文件路径里的业务信息。
6. **Diff 的准确性取决于匹配键选得对不对**。端口被扫描器改写（如 80→0）、路径带随机参数时，会产生假「新增」。遇到这种情况先勾「忽略 URL 查询串」，或退到中等模式，再人工过一遍「疑似」栏。
7. **KEV 镜像依赖 jsDelivr**，国内偶发慢（实测首次拉取约 24 秒）。企业内网无外网时请用「导入 KEV JSON」。
8. 评分里的「暴露面」是**启发式判断**（私网 IP 判内网、域名判公网），不掌握你真实的网络分区。如果资产有 NAT 映射或 VPN 入口，这个值需要人工修正。

## 九、下一步可以加的功能

- XLSX 直接解析（要内嵌 SheetJS，文件会大一些）
- 厂商模板：按报告类型预置字段映射
- Diff 结果支持「两次以上扫描」的时间线（现在只支持两两对比）
- EPSS/KEV 缓存到 localStorage，避免每次重复拉 1.7 MB
- 解析 AI 返回的 JSON，直接渲染成可排序的漏洞表格 + 勾选导出
