# 漏扫报告 AI 分析工具

把漏扫报告**脱敏**后交给 AI 研判，拿到结论再**还原**成真实资产 —— 解决"想用 AI 处理客户报告，但不能把真实 IP 发出去"的矛盾。

单文件，双击 `漏扫报告AI分析工具.html` 即可使用，无需安装。

## 六步流水线

```
导入报告 → 脱敏 → AI 研判 → 还原出报告 → 修复验证 Diff → 优先级重算
```

### 1. 导入
支持厂商 HTML / CSV / TXT 报告，自动识别表格字段。

### 2. 脱敏
IP、域名/主机名、邮箱、MAC 替换成 `[[IP_001]]` 这类占位符，可以额外指定要脱敏的字符串（如客户名、内网域名后缀）。

导出的 `mapping.json` 记录占位符与真实值的对应关系，**只留在本地，不要发给 AI**。

### 3. AI 研判
生成一段带脱敏报告内容的提示词，复制到任意 AI（或配置 API 直接调用），让 AI 给出风险定性、利用可能性和处置建议。

### 4. 还原出报告
把 AI 返回的文本贴回来，用 `mapping.json` 一键把 `[[IP_001]]` 还原成真实 IP，生成可交付的报告。

### 5. 修复验证 Diff
导入两次扫描结果，自动分出已修复 / 仍存在 / 新增。

### 6. 优先级重算
结合 EPSS、CVE KEV 状态和资产上下文，重算修复优先级。

## 设计要点

- **脱敏可逆**：脱敏和还原是同一套映射的两端，AI 全程只见占位符，最终报告是完整资产信息
- **占位符不歧义**：还原时按最长匹配优先，避免 `[[IP_1]]` 误配 `[[IP_10]]`
- **映射表隔离**：明确提示 `mapping.json` 含真实资产，不能外发

## 用法

1. 拖入报告文件，点「开始脱敏」
2. 复制生成的提示词给 AI
3. 把 AI 的回复贴回来，点「还原」
4. 导出报告

## 注意

脱敏只能降低风险，**不能替代合规审查**。是否可以把报告交给外部 AI，请以所在组织的安全策略为准。
