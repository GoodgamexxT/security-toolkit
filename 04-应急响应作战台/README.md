# 应急响应作战台

把突发事件处置固化成可执行流程：**选事件类型 + 选平台 → 出排查思路、命令、判定标准、止损与清除方案**。

单文件，双击 `应急响应作战台.html` 即可使用，无需安装、无需联网。

## 覆盖范围

**6 类事件 × 2 个平台 = 12 个场景**

| 事件 | Windows 侧重点 | Linux 侧重点 |
|---|---|---|
| 挖矿木马 | 高占用进程、WMI 订阅持久化、计划任务复活 | `/proc/*/exe` 指向 deleted、`ld.so.preload` 劫持 |
| 勒索病毒 | 卷影删除痕迹（4688）、横向加密判断 | 加密进程、备份挂载是否被一起加密 |
| 银狐木马 | **白加黑**（合法 exe 加载恶意 DLL）、计划任务、凭据窃取 | 对应到 SSH 后门排查 |
| WebShell | IIS 日志、`WScript.Shell` 特征 | 一句话特征匹配、访问日志倒推 |
| 异常外联 / C2 | 连接-进程映射、DNS 缓存、心跳确认 | `ss`/`lsof`/`tcpdump` |
| 黑链 / 暗链 | 双 UA 对比 | **双 UA 对比**（`Baiduspider` vs 普通 UA）是核心判定 |

每个场景包含四块：

1. **现象特征** —— 先判断像不像
2. **排查步骤** —— 每步带命令，可一键复制
3. **满足这些才算「确认存在」** —— 避免"看到特征就报被打穿"
4. **止损 / 清除修复 / 后续加固** —— 三段处置建议

## 另外四块

- **通用基线**：账号、服务驱动、计划任务、启动项与注册表、WMI 订阅、网络进程、日志（Win 6 组 / Linux 6 组）
- **流程与工具**：7 阶段标准处置流程 + 出场前要准备的工具清单
- **一键采集**：生成只读采集脚本
  - PowerShell：12 个采集分节，跑完自动打包 zip 并算 SHA256
  - Bash：15 个分节，含**命令可信度自检**（检查 ps/ls/netstat 是否被替换）
- **出具报告**：勾选的排查项 + 手填结论 → 导出 HTML / Markdown

## 脚本安全性

采集脚本**只读**：只做查询、导出、打包，不删除、不停服务、不改配置。

两个容易踩的坑已经处理：

- PowerShell 脚本导出时带 **UTF-8 BOM** —— 否则 Windows PowerShell 5.1 会把无 BOM 的 UTF-8 当 GBK 读，中文注释乱码且**直接解析失败**
- Bash 脚本**不能**带 BOM —— 否则 shebang 失效

提交前用 PowerShell AST 解析器和 `bash -n` 校验过语法。

## 用法

1. 选事件类型、选平台，逐项过排查步骤（勾选会记进度并写进报告）
2. 不确定的补一遍「通用基线」
3. 到「一键采集」下载脚本，在目标机器上跑，把压缩包留作附件
4. 到「出具报告」填结论，导出

进度和表单都保存在浏览器本地，关掉页面再打开能接着做。
